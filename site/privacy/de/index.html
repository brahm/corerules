Core Rules · Linux und Windows 11

Datenschutzerklärung

Gültig ab: 28. Oktober 2026

Core Rules erhebt, übermittelt, verkauft oder teilt keinerlei personenbezogene Daten. Es gibt keine Telemetrie, keine Nutzungsanalyse, keine Absturzberichte, keine Werbung, keine Benutzerkonten und keinerlei Tracking.

Was die App speichert, und wo

Alles, was du in Core Rules erstellst, bleibt in Dateien auf deinem eigenen Computer: deine Charaktere, Begegnungen, Schätze und die übrigen Datensätze der ursprünglichen Anwendung, die Kopie der Daten deiner Core Rules-Discs und deine Einstellungen, etwa die Sprache der Oberfläche. Nichts davon wird irgendwohin gesendet. Du kannst diese Dateien jederzeit lesen, verschieben oder löschen, und wenn du die App deinstallierst, bleiben deine Dateien bei dir.

Keine Verbindungen ins Internet

Die App baut von sich aus keine Netzwerkverbindungen auf. Sie sucht nicht nach Updates, sendet keine Nutzungsstatistiken und kontaktiert keinen Server. Das Internet kommt nur ins Spiel, wenn du in der Hilfe einem Weblink folgst: Die Seite öffnet sich dann in deinem Standardbrowser, und es gilt die Datenschutzerklärung dieser Website.

Stores und Betriebssystem

Wenn du Core Rules über den Microsoft Store, Flathub oder die Veröffentlichungen auf GitHub installierst, liefert dieser Dienst den Download gemäß seiner eigenen Datenschutzerklärung aus. Bestandteile des Betriebssystems, die die App nutzt, etwa Microsoft Edge WebView2, das unter Windows die Hilfe anzeigt, folgen den Einstellungen und Richtlinien ihrer Hersteller. Core Rules erhält von keinem davon Daten.

Diese Website

Diese Website wird auf GitHub Pages gehostet. Sie setzt keine Cookies und verwendet keine Analysewerkzeuge. GitHub kann technische Informationen wie IP-Adressen protokollieren, um seinen Dienst sicher zu halten, wie in der GitHub-Datenschutzerklärung beschrieben. Die Hauptseite lädt ihre Schriften von Google Fonts; diese Seite nicht.

Kinder

Da Core Rules von niemandem Daten erhebt, erhebt es auch keine Daten von Kindern.

Änderungen dieser Erklärung

Sollte sich diese Erklärung ändern, wird die neue Fassung auf dieser Seite mit einem neuen Gültigkeitsdatum veröffentlicht. Core Rules ist Open Source, daher kann jeder im Quellcode nachprüfen, was es tut.
