Core Rules · Linux e Windows 11

Informativa sulla privacy

Data di entrata in vigore: 28 ottobre 2026

Core Rules non raccoglie, trasmette, vende né condivide alcun dato personale. Non ha telemetria, statistiche d'uso, segnalazione degli arresti anomali, pubblicità, account utente né tracciamento di alcun tipo.

Cosa conserva l'applicazione, e dove

Tutto ciò che crei in Core Rules resta in file sul tuo computer: i tuoi personaggi, incontri, tesori e gli altri archivi dell'applicazione originale, la copia dei dati dei tuoi dischi di Core Rules e le tue preferenze, come la lingua dell'interfaccia. Niente di tutto ciò viene inviato altrove. Puoi leggere, spostare o eliminare questi file in qualsiasi momento, e disinstallare l'applicazione lascia i tuoi file nelle tue mani.

Nessuna connessione a internet

L'applicazione non effettua alcuna connessione di rete di propria iniziativa. Non cerca aggiornamenti, non invia statistiche d'uso e non contatta alcun server. Internet entra in gioco solo quando scegli di seguire un collegamento web nella guida: la pagina si apre allora nel tuo browser predefinito e si applica l'informativa sulla privacy di quel sito.

Store e sistema operativo

Se installi Core Rules da Microsoft Store, da Flathub o dalle versioni pubblicate sul GitHub del progetto, quel servizio fornisce il download secondo la propria informativa sulla privacy. I componenti del sistema operativo usati dall'applicazione, come Microsoft Edge WebView2, che mostra la guida su Windows, seguono le impostazioni e le politiche dei rispettivi produttori. Core Rules non riceve dati da nessuno di essi.

Questo sito

Questo sito è ospitato su GitHub Pages. Non usa cookie né strumenti di analisi. GitHub può registrare informazioni tecniche, come gli indirizzi IP, per mantenere sicuro il proprio servizio, come descritto nella GitHub Privacy Statement. La pagina principale carica i caratteri da Google Fonts; questa pagina no.

Minori

Poiché Core Rules non raccoglie dati da nessuno, non ne raccoglie nemmeno dai minori.

Modifiche a questa informativa

Se questa informativa cambierà, la nuova versione sarà pubblicata in questa pagina con una nuova data di entrata in vigore. Core Rules è open source, quindi chiunque può verificare cosa fa nel suo codice sorgente.
