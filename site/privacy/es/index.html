Core Rules · Linux y Windows 11

Política de privacidad

Fecha de entrada en vigor: 28 de octubre de 2026

Core Rules no recopila, transmite, vende ni comparte ningún dato personal. No tiene telemetría, analíticas, informes de errores, publicidad, cuentas de usuario ni seguimiento de ningún tipo.

Qué guarda la aplicación, y dónde

Todo lo que creas en Core Rules se queda en archivos de tu propio ordenador: tus personajes, encuentros, tesoros y los demás registros de la aplicación original, la copia de los datos de tus discos de Core Rules y tus preferencias, como el idioma de la interfaz. Nada de ello se envía a ninguna parte. Puedes leer, mover o borrar estos archivos cuando quieras, y desinstalar la aplicación deja tus archivos en tus manos.

Ninguna conexión a internet

La aplicación no realiza ninguna conexión de red por su cuenta. No busca actualizaciones, no envía estadísticas de uso ni contacta con ningún servidor. Internet solo interviene cuando decides seguir un enlace web de la ayuda: la página se abre entonces en tu navegador predeterminado y se aplica la política de privacidad de ese sitio.

Tiendas y sistema operativo

Si instalas Core Rules desde Microsoft Store, Flathub o las versiones publicadas en el GitHub del proyecto, ese servicio entrega la descarga según su propia política de privacidad. Los componentes del sistema operativo que usa la aplicación, como Microsoft Edge WebView2, que muestra la ayuda en Windows, siguen la configuración y las políticas de sus fabricantes. Core Rules no recibe datos de ninguno de ellos.

Este sitio web

Este sitio está alojado en GitHub Pages. No usa cookies ni analíticas. GitHub puede registrar información técnica, como direcciones IP, para mantener seguro su servicio, según la Declaración de Privacidad de GitHub. La página principal carga sus fuentes desde Google Fonts; esta página de la política no.

Menores

Como Core Rules no recopila datos de nadie, tampoco recopila datos de menores.

Cambios en esta política

Si esta política cambia, la nueva versión se publicará en esta página con una nueva fecha de entrada en vigor. Core Rules es de código abierto, así que cualquiera puede comprobar lo que hace en su código fuente.

Contacto

Las preguntas sobre esta política pueden plantearse en el registro de incidencias del proyecto o a través de wagnerbrahm.com.br.
