Politique de confidentialité

Date d'entrée en vigueur : 28 octobre 2026

Core Rules ne collecte, ne transmet, ne vend et ne partage aucune donnée personnelle. Il n'a ni télémétrie, ni statistiques d'utilisation, ni rapports de plantage, ni publicité, ni compte utilisateur, ni suivi d'aucune sorte.

Ce que l'application conserve, et où

Tout ce que vous créez dans Core Rules reste dans des fichiers sur votre propre ordinateur : vos personnages, rencontres, trésors et les autres fiches de l'application d'origine, la copie des données de vos disques Core Rules et vos préférences, comme la langue de l'interface. Rien de tout cela n'est envoyé où que ce soit. Vous pouvez lire, déplacer ou supprimer ces fichiers à tout moment, et désinstaller l'application vous laisse vos fichiers.

Aucune connexion à Internet

L'application n'établit aucune connexion réseau d'elle-même. Elle ne recherche pas de mises à jour, n'envoie pas de statistiques d'utilisation et ne contacte aucun serveur. Internet n'intervient que lorsque vous choisissez de suivre un lien web de l'aide : la page s'ouvre alors dans votre navigateur par défaut, et c'est la politique de confidentialité de ce site qui s'applique.

Boutiques et système d'exploitation

Si vous installez Core Rules depuis le Microsoft Store, Flathub ou les versions publiées sur le GitHub du projet, ce service fournit le téléchargement selon sa propre politique de confidentialité. Les composants du système d'exploitation qu'utilise l'application, comme Microsoft Edge WebView2, qui affiche l'aide sous Windows, suivent les réglages et les politiques de leurs éditeurs. Core Rules ne reçoit aucune donnée d'aucun d'eux.

Ce site

Ce site est hébergé sur GitHub Pages. Il ne dépose aucun cookie et n'utilise aucun outil de mesure d'audience. GitHub peut enregistrer des informations techniques, comme les adresses IP, pour assurer la sécurité de son service, comme le décrit la Déclaration de confidentialité de GitHub. La page principale charge ses polices depuis Google Fonts ; cette page de la politique, non.

Enfants

Comme Core Rules ne collecte de données auprès de personne, il n'en collecte pas non plus auprès des enfants.

Modifications de cette politique

Si cette politique change, la nouvelle version sera publiée sur cette page avec une nouvelle date d'entrée en vigueur. Core Rules est un logiciel libre : chacun peut vérifier ce qu'il fait dans son code source.

Contact
