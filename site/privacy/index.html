Core Rules · Linux and Windows 11

Privacy policy

Effective date: 28 October 2026

Core Rules does not collect, transmit, sell or share any personal data. It has no telemetry, no analytics, no crash reporting, no advertising, no user accounts and no tracking of any kind.

What the app keeps, and where

Everything you make in Core Rules stays in files on your own computer: your characters, encounters, treasure and the other records of the original application, the copy of the data from your Core Rules discs, and your preferences, such as the language of the interface. Nothing of it is sent anywhere. You can read, move or delete these files at any time, and uninstalling the app leaves your own files in your hands.

No connections to the internet

The app makes no network connections of its own. It does not check for updates, send usage statistics or contact any server. The only time the internet comes into play is when you choose to follow a web link in the help: the page then opens in your default web browser, and that website's own privacy policy applies.

Stores and the operating system

If you install Core Rules from the Microsoft Store, Flathub or the project's GitHub releases, that service delivers the download under its own privacy policy. Components of the operating system that the app uses, such as Microsoft Edge WebView2, which shows the help on Windows, follow the settings and policies of their makers. Core Rules receives no data from any of them.

This website

This website is hosted on GitHub Pages. It sets no cookies and has no analytics. GitHub may log technical information, such as IP addresses, to keep its service secure, as described in the GitHub Privacy Statement. The main page loads its fonts from Google Fonts; this policy page does not.

Children

Because Core Rules collects no data from anyone, it collects none from children either.

Changes to this policy

If this policy ever changes, the new version will be published on this page with a new effective date. Core Rules is open source, so anyone can check what it does in its source code.

Contact

Questions about this policy can be asked on the project's issue tracker or through wagnerbrahm.com.br.
