Core Rules · Linux e Windows 11

Política de privacidade

Data de vigência: 28 de outubro de 2026

O Core Rules não coleta, transmite, vende nem compartilha nenhum dado pessoal. Ele não tem telemetria, análise de uso, relatórios de falhas, publicidade, contas de usuário nem rastreamento de nenhum tipo.

O que o aplicativo guarda, e onde

Tudo o que você cria no Core Rules fica em arquivos no seu próprio computador: seus personagens, encontros, tesouros e os demais registros do aplicativo original, a cópia dos dados dos seus discos do Core Rules e suas preferências, como o idioma da interface. Nada disso é enviado a lugar algum. Você pode ler, mover ou apagar esses arquivos quando quiser, e desinstalar o aplicativo deixa seus arquivos nas suas mãos.

Nenhuma conexão com a internet

O aplicativo não faz nenhuma conexão de rede por conta própria. Ele não procura atualizações, não envia estatísticas de uso e não contata nenhum servidor. A internet só entra em cena quando você decide seguir um link da web na ajuda: a página abre então no seu navegador padrão, e vale a política de privacidade daquele site.

Lojas e sistema operacional

Se você instala o Core Rules pela Microsoft Store, pelo Flathub ou pelas versões publicadas no GitHub do projeto, esse serviço entrega o download segundo a sua própria política de privacidade. Os componentes do sistema operacional que o aplicativo usa, como o Microsoft Edge WebView2, que mostra a ajuda no Windows, seguem as configurações e políticas de quem os fez. O Core Rules não recebe dados de nenhum deles.

Este site

Este site é hospedado no GitHub Pages. Ele não usa cookies nem ferramentas de análise. O GitHub pode registrar informações técnicas, como endereços IP, para manter seu serviço seguro, conforme a Declaração de Privacidade do GitHub. A página principal carrega suas fontes do Google Fonts; esta página da política não.

Crianças

Como o Core Rules não coleta dados de ninguém, também não coleta dados de crianças.

Alterações desta política

Se esta política mudar, a nova versão será publicada nesta página com uma nova data de vigência. O Core Rules é de código aberto, então qualquer pessoa pode conferir o que ele faz no seu código-fonte.
